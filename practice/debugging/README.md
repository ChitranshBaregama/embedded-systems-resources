# Debugging practice

Begin with a symptom and competing hypotheses. Propose a discriminating observation before changing code. Use Q0008, HardFault examples, bus recovery, dropped ISR events and corrupted packets. Deliver raw evidence, root cause, minimal fix and regression test. Score experiment quality, not speed of guessing.
