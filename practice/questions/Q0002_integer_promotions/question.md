# C Fundamentals — Integer Promotions

## Problem
Write a small C program that demonstrates integer promotion and usual arithmetic conversions using `uint8_t`, `int8_t`, `uint16_t`, `int`, and `unsigned int`.

Predict every result before running it and explain *why* C produced that result.


## Scored contract clarification

Record sizeof and limits of the types and the compiler/ABI. Separate defined conversions from undefined behavior; do not execute deliberate UB as evidence of a guaranteed result. Supply at least six predictions before running and explain any target-dependent result.
