# DSA practice

Use arrays/two pointers, sliding windows, binary search, lists, stacks/queues, hash maps, trees, heaps, graph traversal, topological ordering, greedy, dynamic programming and bounded-memory variants. For each: state invariant, complexity, allocation limit and overflow behavior. Choose one familiar and one transfer problem; do not memorize a single code shape.

Use the [progress ledger](../progress/README.md) for real attempts and the [readiness gates](../../career/READINESS_GATES.md) for advancement.
