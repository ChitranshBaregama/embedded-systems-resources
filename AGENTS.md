# Working in this repository

Read career/SYSTEM_SPEC.md and career/READINESS_GATES.md before coaching scored practice. Preserve the existing reference library and solved examples.

The learner writes scored implementations. Supply requirements, tests, review and progressive hints; provide a full solution only after an attempt and an explicit request. Do not populate practice solution.c files with AI implementations or count AI-created material as learner progress.

Use practice/progress/attempts.csv as the attempt ledger. Never fabricate results, solved states, retention passes, project measurements or mock scores. Keep unattempted exercises separate from failing infrastructure. Run python3 scripts/learning.py validate and python3 scripts/check-links.py after curriculum changes. Run python3 -m unittest discover -s scripts -p 'test_learning.py' after tooling changes.

Keep employer/confidential material and secrets out. Preserve source provenance during migration. Do not archive the source repository until the migration acceptance checklist has been completed. Do not send external contribution messages without user instruction.
