# Host practice container

Provides Debian bookworm, GCC/G++, Make, GDB, Python and Git for host exercises. Open the repository with a compatible Dev Containers client or Codespaces. Image build has not been executed in this workspace; packages are not a reproducible lockfile. Record versions with real attempt evidence.

This does not configure USB debugging, cross compilers, Zephyr, FreeRTOS or a hardware target. Use the existing code instructions or upstream setup for those environments. Container setup never fills learner implementations or marks tasks solved.
